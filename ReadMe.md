🤖 Shree — Personal AI Assistant

Shree is a personal AI assistant designed to help users in their day-to-day tasks, inspired by intelligent assistants like J.A.R.V.I.S and FRIDAY. The goal of this project is to build a smart, interactive system that can answer questions, assist with tasks, and eventually integrate deeply with user devices.


🚀 Features
💬 General Question Answering
Answer questions across various domains like math, general knowledge, and everyday queries.
🧠 AI-Powered Responses
Currently powered by local LLMs using Ollama.
🖥️ Interactive UI
Built with modern frontend technologies for a smooth and engaging experience.
🔊 Future Voice Interaction (Planned)
Control the assistant using voice commands.
📂 Device Assistance (Planned)
Manage files and assist with system-level tasks (with user permission).
🔌 Smart Device Integration (Planned)
Control external devices and IoT systems.
🛠️ Tech Stack
Frontend: JavaScript, TypeScript, React.js
3D / UI Enhancements: Three.js
AI Model: Ollama (local LLMs)
Future Scope: Custom-trained AI model


📌 Usage
Run the application locally
Interact with the assistant via the UI
Ask questions or give prompts
(Future) Use voice commands for interaction
🔮 Future Improvements
🧠 Development of a custom AI model
🎙️ Full voice assistant capabilities
📁 File system management
🏠 Smart home and IoT control
📱 Cross-device integration (mobile, desktop, etc.)
🔐 Enhanced security and permission systems
